# W7 GradientAlphaMode — rapport d’intégration

## Résultat

Les 11 tests publics de `W7GradientAlphaSurfacePixelTest` passent, avec le second rendu vérifié lui aussi par preuves natives `Render` et `Readback`. Les contrôles voisins W7 mixed-root AA et W5b fractional Rect passent. La suite W5c reste à 27 tests dont les cinq échecs préexistants listés ci-dessous. Les cas W5f sélectionnés satisfont leurs assertions/XML, mais le processus Gradle se termine avec le code 133 après les tests : ils ne sont donc pas comptés verts.

Le helper natif SRC ne désactive plus le blending sans contexte : `blend=null` est limité aux identités `PremulSrc`, `sampleCount==1` et programme direct authentifié. Les programmes analytic, stencil-cover, clip et mask conservent leur état One/Zero. À ce point d’identité, le programme Direct* est le jeton de route scellé dont l’admission structurale garantit `sourceCoverage=None` ; l’identité ne transporte pas un champ brut de coverage.

Le contrôle public SRC+AA envisagé ne peut pas être exprimé dans la géométrie actuellement admise. Son exécution échoue avant publication avec `unsupported.material.runtime_effect.renderer_preflight: Every material packet must have its sealed geometry host template`; le test exploratoire a été retiré sans ouvrir l’admission ni modifier l’oracle. Le test public `wrappersAndMixedAaRootPreserveAlphaMode` couvre toutefois la coexistence d’un gradient avec un sibling Rect stroke AA déjà admis. Aucun témoin de pixels pour SRC à couverture partielle n’est revendiqué.

## Budget statique

`B = 25 220` octets, calculé avant l’exécution du test de seuil : cible `4` + readback aligné `256` + allocations de capacité V/I/U `16 384 + 4 096 + 4 096` + deux uniforms V4 (`2 × (112 header + 48 inverse CTM) = 320`) + un slab V4 partagé de deux stops `64` = `25 220`. B est accepté ; B−1 refuse avec `resource.material.gradient.stop-budget`, laisse le sentinel inchangé, puis le Surface est discardé et une même Surface récupérée rend deux fois. Le cas mixte STRAIGHT/working-SRGB + PREMULTIPLIED partage bien ce slab.

## RED, provenance et corrections de l’oracle

- Le vrai RED comportemental est `red-src`, pas les premiers essais invalides : XML `/private/tmp/kanvas-w7-alpha-mode.vpi7cG/red-src/xml/TEST-org.graphiks.kanvas.surface.W7GradientAlphaSurfacePixelTest.xml`, 2/2 assertions échouées, Gradle exit 1. Deux témoins GPU publics SOURCE-only avec oracle SRC correspondaient au même rendu. Le stop transparent donne R observé 92 contre [187, 188] attendu ; les deux stops d’alpha non nul donnent R observé 80 contre [108, 109]. Les contrôles STRAIGHT de référence restaient acceptés. Le mismatch identifiait le mode PREMULTIPLIED ignoré par le chemin shader avant intégration.
- Les essais `red2`/`red3` ne sont pas des RED valides : `red2` échoue à `requireBounded` avant le renderer, avec 3–4 codes possibles ; `red3` compare le Surface avec fond blanc à un oracle dont la destination est transparente. Ils n’ont pas motivé de changement de pixel, de tolérance ou d’enveloppe.
- La fixture historique Picture15 a été capturée avant le changement d’archiveur. Le test temporaire de capture sort exit 1 intentionnellement en exportant la base64 via son assertion ; son XML `fixture-capture/xml/TEST-org.graphiks.kanvas.picture.W7HistoricalPictureFixtureCaptureTest.xml` documente cet export, ce n’est pas un test vert. La fixture version 15 est ensuite réellement décodée/rejouée par `historicalPicture15StraightGradientReplaysItsWhiteBackground` ; le nouveau replay conserve le fond blanc historique et passe dans W7 final.
- Intégration de l’oracle : W7 integration2 avait des attentes multistop/hard-stop calculées avec le chemin STRAIGHT parce que `expectedShaderTree` omettait `alphaMode`. L’oracle indépendant propage maintenant ce mode dans `gradientStops` et `gradientSource`, y compris les choix avant/après l’intervalle CLAMP, et dans `expectedGradientPixel`. Son chemin PREMULTIPLIED suit le calcul endpoint-alpha min-partitionné ; les pixels attendus ne sont pas dérivés des valeurs GPU observées.
- Intégrations 3→4→5 : le premier contrôle AA utilisait un pixel de gradient intermédiaire non justifié par la scène ; à (3,3), l’attendu [188,0,187] ne correspondait pas au rendu observé [143,143,255]. L’essai suivant a révélé un oracle AA non borné (142–144) et a été rejeté, sans élargir son enveloppe. La scène/assertion a été resserrée à des zones hard-stop déterministes, tout en gardant le sibling Rect stroke AA et le gradient dans la même racine ; seuls les points déterminés par la scène/l’oracle sont comparés, sans reprendre le pixel observé comme attendu. L’intégration5 a alors passé 11/11 avant le correctif de portée SRC. Le rerun final 11/11 comprend le garde SRC et les preuves natives sur les deux rendus.
