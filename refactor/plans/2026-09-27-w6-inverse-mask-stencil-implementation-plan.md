# W6 InverseMask Stencil Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre correctement un fill inverse W4e sous clip mask dans une layer W6 et geler ses sites natifs Geometry/Zero avant les gates de budget.

**Architecture:** `:math` conserve le domaine et l'intérieur du path. Pour Geometry, W4e publie un producer stencil de l'intérieur puis un color cover du domaine avec stencil zéro et clip normal ; pour Zero publié, un seul color cover suffit. W5/W6 transportent le domaine inverse, et le renderer traduit les phases gelées. Ce plan ferme seulement cette portion de 2A0c.IIIb/c ; le plan W6 principal garde 2A0c.IV, 2A0d, 2A1 et 2B.

**Tech Stack:** Kotlin, Gradle, `:math`, `:gpu-plan`, `:gpu-renderer`, Surface public, WebGPU/Metal.

**Spec:** `refactor/specs/2026-09-27-w6-inverse-mask-stencil-design.md` ; consulter aussi `refactor/plans/2026-09-26-w6-final-gates-implementation-plan.md` pour les gates successeurs.

## Global Constraints

- Objets et calculs géométriques uniquement dans `:math`, nomenclature I/F32/F64 ; aucune nouvelle géométrie dans le renderer.
- Scope : W4e single-sample hard-edge publié par W6 ; ni fonts, codecs, GM, dashboard, suite Skia globale, ni test d'infrastructure du code.
- Oracles publics fixés avant `Surface`/`PictureRecorder`, pixels causaux et scopes `Render` + `Readback` ; ne pas ajuster un oracle pour faire passer la production.
- Les commandes shell commencent par `rtk`. Gradle : `--no-daemon --no-parallel --no-build-cache`, une invocation à la fois. Reporter séparément XML JUnit, exit Gradle et crash natif 133/134 (`UNKNOWN`).
- Un subagent Terra implémente chaque tâche ; Sol fait la revue indépendante après commit. Astra uniquement si un blocage architectural inédit persiste. La PR W6 reste Draft et empilée sur #2408 ; ne pas annoncer W6 complet dans ce sous-plan.
- Le témoin triangle existant est une modification non committée de `W6aLayerW4W5SurfacePixelTest.kt` : le préserver, l'indexer seulement avec Task 1.

## Review Focus

1. Extérieur du triangle mais intérieur du clip concave : bleu, jamais transparent ni couleur hors clip (Task 1, témoin 6×6).
2. Même-sens contours et trou `INVERSE_EVEN_ODD` : le trou redevient coloré, contrairement à `Replace(1)` (Task 2, grille 8×8).
3. Origine de layer non nulle : mask, D24S8 et domaine se translatent une seule fois (Task 2, témoin translaté).
4. Deux draws inverses successifs : le second ne lit pas le stencil du premier (Task 2, témoin rouge/bleu).
5. Path inverse vide sous clip non rectangulaire : sortie égale au clip normal, sans producer fictif (Task 2, témoin Zero). Les préservations `Mask`/`InverseDomain` restent dans les sélecteurs des Tasks 2–3.
