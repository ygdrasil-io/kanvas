# W6 InverseMask Integer-Scissor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Faire correspondre le producer `InverseMask.Geometry` DirectTriangle non-AA de W6 aux spans entiers de Skia, sans triangle GPU pour ce producer ni changement des autres routes.

**Architecture:** `:math:geometry` décide et rebase une seule fois les spans I32 ; W4e publie cette autorité avant l'admission et retire les 3/3 V/I provisoires du slab partagé. W6 transporte les scissors locaux jusqu'à un producer fullscreen qui émet un `SetScissor` et un `Draw(3)` par span dans un seul pass D24S8 ; Empty ne dessine rien, et le cover reste distinct.

**Tech Stack:** Kotlin Multiplatform, Gradle, `:math:geometry`, `:gpu-plan`, `:gpu-renderer`, Surface public, WebGPU/Metal.

**Spec:** `refactor/specs/2026-09-28-w6-inverse-mask-scan-spans-design.md` ; topologie de base `refactor/specs/2026-09-27-w6-inverse-mask-stencil-design.md`.

## Global Constraints

- Seulement `InverseMask.Geometry` DirectTriangle, single-sample, hard-edge W6 ; `InverseMask.Zero`, direct ordinaire, fan et `InverseDomain` restent distincts.
- Géométrie et rebase dans `:math`, nomenclature I32/F32/F64 ; pas de calcul d'intersection, de NDC ni de biais dans le renderer.
- La référence numérique est Skia `93912d50850d`, non-AA `shift=0`, branche par défaut de FDot6 ; si le binaire oracle active `SK_RASTERIZE_EVEN_ROUNDING`, établir ses pixels séparément avant de revendiquer sa parité.
- Un seul packet préparé par producer, même Empty ; N draws positifs portent chacun le même payload sémantique gelé, Empty zéro draw et zéro slice V/I.
- Plafond frame-wide de **4 096** draws de producer scan-span, occurrences répétées incluses, refus sur le 4 097e avant publication et `device.create*` ; ce plafond est indépendant de `frameLocalBudgetBytes`.
- Oracle littéral RED 6×6 inchangé ; tests de résultat géométrique dans `:math` et comportement Surface public ciblé seulement. Aucun test d'infrastructure du code, GM/dashboard/suite Skia globale, fonts/codecs.
- Shell préfixé `rtk` ; Gradle `--no-daemon --no-parallel --no-build-cache`, une invocation à la fois. Conserver XML JUnit, exit Gradle et exit natif macOS 133/134 séparés.
- Préserver le test RED déjà non committé `W6aLayerW4W5SurfacePixelTest.kt` et les deux fichiers `:math` partiels ; ne les indexer qu'avec la tâche correspondante.
- SDD : Terra implémente, Sol relit chaque commit ; Astra uniquement pour blocage architectural persistant. Branche `codex/w6-final-gates`, Draft PR empilée sur #2408 ; cette extension seule ne ferme pas 2A0c, 2A1 ou 2B.

## Review Focus

1. Clipping vertical avec coordonnées négatives : la première ligne visible utilise le `fX` avancé, non une intersection F32 recalculée (Task 1, test `negative clip advances edge before rounding`).
2. Translation de layer et bornes I32 : une soustraction checked unique donne les mêmes pixels ou un refus avant allocation (Tasks 1/3, test math local et Surface 8×8).
3. Triangle Geometry sans centre couvert : producer clear-only, cover inchangé, sans slice ni draw fictif (Task 3, Surface subpixel).
4. Plusieurs occurrences, cache ou `commonSource` : le 4 097e draw est refusé même si la source géométrique est identique (Task 4, deux draws publics du même path).
5. Frontière du fullscreen sur grande cible : les quatre coins de 700×700, dont (699,0), restent couverts par le producer et non par un artefact de son hypoténuse (Task 3, Surface 700×700).
