## Review Focus

1. Coverage accidentally becomes hard, complemented after resolve, or multiplied twice: Task1 freezes an independent half-covered diagonal-edge oracle, disjoint from C0/C1/C².
2. Original alpha is applied by both source and consumer: Task1 compares alpha128 fractional SrcOver once versus twice over exact clear, and explicitly excludes source-alpha-squared before native execution.
3. Second Picture occurrence reuses first resource mapping/origin/material destination: Task1 replays the same Picture at two translations; the opaque nested family uses distinct Blue/Red backgrounds, memory and wire variants, every pixel and repeat checked.
4. Inverse winding and parity collapse into the same stencil operation: Task1 adds nested same-direction contours with distinct expected central coverage, both memory and wire variants.
5. Rebinding widens scissor/domain or silently admits an unsupported aggregate: Task1 keeps explicit hard clipping, checks every outside pixel, and runs the existing perspective-composite refusal/sentinel/discard/recovery plus ordinary AA Picture regressions.
